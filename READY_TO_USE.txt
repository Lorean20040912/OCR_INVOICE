🚀 TO PROCESS YOUR FIRST INVOICE:

Step 1: Get an Invoice Image
  - Scan a document, or
  - Take a photo with your phone

Step 2: Copy to Correct Folder
  Based on image quality:
  
  Excellent (scanned/perfect):
    copy invoice.jpg test_invoices\excellent_quality\
  
  Good (phone photo, good light):
    copy invoice.jpg test_invoices\good_quality\
  
  Poor (phone photo, dim light):
    copy invoice.jpg test_invoices\poor_quality\
  
  Very Poor (blurry/tilted):
    copy invoice.jpg test_invoices\very_poor_quality\

Step 3: Run the Processor
  .\venv\Scripts\python.exe process_single_invoice.py test_invoices\good_quality\invoice.jpg

Step 4: Check Results
  - Results printed to console
  - Debug images in debug_preprocessing/ folder
  - See what each step did to the image

💡 FEATURES:

8-Step Preprocessing:
  1. Auto-rotation (fixes tilted images)
  2. Shadow removal (CLAHE)
  3. Contrast enhancement (CLAHE)
  4. Denoising (Bilateral + NLM)
  5. Text sharpening
  6. Binarization (3 methods, auto-select best)
  7. Debug image saving
  8. Automatic best-method selection

Dual OCR Engines:
  • EasyOCR (neural networks - better for poor quality)
  • Tesseract (traditional - better for scans)
  • Auto-selects best based on confidence

Field Extraction:
  • Invoice number (multiple formats)
  • Invoice date (multiple formats)
  • Contractor/vendor name
  • IDNO (13-digit ID for Moldova)
  • Total amount (with/without currency)
